# ЛР 1. Оптимизация портфеля ценных бумаг

НИЯУ МИФИ · Б24-507 · № 14 · вариант 5 · seed 10014

## Запуск Windows 11

```powershell
python -m pip install -r requirements.txt
python main.py
python -m unittest discover -s tests -v
```

Можно запускать `main.py` кнопкой Run. Рабочая директория — папка `lab1`. Скрипт не требует аргументов.

## Файлы

- `data/portfolio.json` — исходные данные; `generate_data.py` — воспроизводимая генерация (`python generate_data.py`).
- `model.py` — загрузка, LP-модель, HiGHS; `verify.py` — независимый контроль через NumPy.
- `main.py` — три сценария, теневые цены, отчёт и график.
- `results/` — таблица распределения, сценарии, проверка, запись решения солвера, график.
- `REPORT.md` — результаты прогона; `THEORY.md` — разбор модели и вопросы к защите.

**Повторная генерация данных перезаписывает исходный JSON**, но при том же seed получаются те же значения.

`optimal` означает найденный оптимум; `infeasible` — ни один портфель не удовлетворяет ограничениям; `unbounded` — математически неограниченный доход; `time_or_iteration_limit` — оптимальность не подтверждена. Для текущей модели сумму долей и верхние границы проверяет независимый модуль. Сумма долей и максимум 45% на актив исключают неограниченность.

Все показатели условные, финансовой рекомендацией не являются.

## Альтернативный запуск

На Windows 11 можно запустить `run_windows.cmd`: он создаст `.venv` через установленный Python 3.14, установит зависимости, выполнит расчёт и тесты.
